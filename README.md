# TaskFlow

A responsive, frontend-only task manager built with React and Vite. Tasks are managed in React state and saved in this browser's localStorage; no backend or database is used.

## Run locally

```sh
npm install
npm run dev
```

## Available checks

```sh
npm run lint
npm run build
```

Tasks can be created, edited, completed, deleted, searched by title, and filtered by status or priority. The dashboard statistics update from the current task list.
